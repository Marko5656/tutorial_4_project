# Tutorial 4 - Mark Johnson 

## Purpose
This repository was created for my Git and GitHub tutorial assignment.  
It demonstrates how to use Git for version control and GitHub for collaboration.

## Steps Followed
1. Installed Git and created a GitHub account.
2. Initialized a local repository using `git init`.
3. Created and switched to a new branch.
4. Added a sample file (`print_name.py`) that prints my first and last name.
5. Committed the changes with a message.
6. Pushed the branch to GitHub.
7. Created a Pull Request and had it reviewed and merged.
